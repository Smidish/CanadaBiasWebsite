Snippet library

Every building block of a path, live, next to the exact code that produces it. Copy a snippet, change the words and numbers, paste it into a content file.

1 · Find the slot

Open any page with ?slots in the URL (e.g. path.html?rq=1&slots). Every editable block is outlined and labelled with the file and field it comes from.

2 · Try it in the sandbox

Paste into js/content/sandbox.js and open sandbox.html to scroll through it exactly as it will appear.

3 · Move it into place

Paste into js/content/rqN.js (or tour.js). Each route there starts with a CONTENT banner comment listing the fields you can edit.
